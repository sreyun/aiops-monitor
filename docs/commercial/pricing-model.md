# 商业化定价模型建议

> 原则：**节点数（基础）+ AI 用量（可选）** 双轨计费，与代码中已内置的
> AI 成本核算能力一一对应，避免“功能订阅”式定价带来的交付复杂度。

## 1. 定价口径

| 维度 | 计费单位 | 代码对应 |
|---|---|---|
| 基础平台 | 受管节点/主机（Agent 计） | `GET /api/v1/summary` 在线主机数 |
| AI 对话/诊断 | 每百万 input/output token | `AIConfig.InputPricePer1M` / `OutputPricePer1M` |
| AI 用量护栏 | 每用户每日配额 / 单次成本上限 | `DailyQuotaPerUser` / `MaxCostPerQueryCNY` |
| 模型级价格覆盖 | 按模型单价 | `ModelPricingJSON` |
| 企业服务 | 年费（SLA/技术支持/合规交付） | 线下合同 |

## 2. 套餐示例（可按市场调整）

| | 社区版 | 专业版 | 企业版 |
|---|---|---|---|
| 许可 | MIT（自托管） | 商业订阅 | 商业订阅 |
| 节点 | 不限 | ≤200 节点 | 不限 + 集群 |
| AI 用量 | 自带 Key | 自带 Key + 成本护栏 | 托管网关 / BYOK |
| 支持 | 社区 | 工单 SLA 4h | 专属客户成功 + SLA 1h |
| 合规 | 基础 | 审计导出 | 等保/SOC2 材料 + 私有化交付 |

## 3. 计费落地建议

1. 在配置页提供“成本估算器”：输入预估 token 量，按 `ModelPricingJSON`
   实时测算月度 AI 成本。
2. 在 `ai_usage.go` 的用量视图上增加“按团队/按用户”成本拆分（当前已记录
   `cost_estimate`、`actor`，可直接聚合）。
3. 企业版开通 `license` 配置项：节点数软限制 + 超限告警（不强制断服，
   以友好提示引导续费）。

## 4. 商业注意点

- MIT 开源部分保留“自托管免费”，企业版卖**治理/合规/服务**而非锁功能，
  避免社区口碑反噬。
- AI 用量按 token 计量时，务必在文档中说明“自带 Key”与“托管网关”两种
  模式的成本归属差异。

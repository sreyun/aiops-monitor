# 企业版路线图（MIT 开源 + 企业订阅）

> 策略：开源版保持完整核心功能（MIT），企业版聚焦**治理、合规、规模、服务**，
> 用服务与合规能力变现，不阉割社区功能。

## 1. 企业版候选能力清单

### 治理与合规（第一优先，P0）

- 多租户/多团队：按团队隔离主机、工单、看板与 AI 用量（当前为单租户 RBAC）。
- 审计导出：可配置的审计归档（S3/本地）+ 保留策略。
- 合规基线：一键生成“等保/CIS 自评报告”（复用 host_security 扫描结果）。
- 会话审计增强：终端/桌面会话操作级导出（含时间线、命令、回放文件打包）。

### 规模与可靠性（第二优先，P1）

- server 多副本 + 会话亲和与任务抢占。
- PostgreSQL 归档/分区自动化 + 备份演练（PITR）。
- 监控自身健康（server/agent 心跳 SLA 报表）。

### 生态集成（第三优先，P2）

- ITSM 双向同步：Jira / ServiceNow / 飞书审批流（工单↔外部系统）。
- SAML/企业微信深度 SSO（当前为 OIDC/飞书/钉钉/企微 OAuth）。
- OTLP 接入（metrics/traces 收编）。

### 服务与交付（贯穿）

- 专属支持 SLA、故障应急陪跑、私有化安装包（离线镜像 + 安装盘）。
- 客户成功：季度效果复盘（引用 `closed-loop-weekly-report.md` 的 KPI）。

## 2. 阶段路线（建议 4 个季度）

| 阶段 | 主题 | 交付物 |
|---|---|---|
| Q1 | 工程信誉 | CI 全绿、SBOM/签名、默认安全基线、前端构建链 |
| Q2 | AI 闭环可证明 | 效果周报、成本护栏、模型路由、Skill 市场格式 |
| Q3 | 生态与规模 | OTLP、OpenAPI 契约、千台压测、多副本 |
| Q4 | 商业化 | 企业版许可、计费仪表盘、合规材料包 |

## 3. 开源/商业边界（避免社区反噬）

- 社区版永久免费、功能完整；企业版不开新锁。
- 企业版卖点全部为“治理/合规/规模/服务”，社区文档同步公开。
- 贡献者协议与商标使用规范需在商业化前落地。
